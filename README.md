## 🌟 Featured Projects

* **[SRTN_-_RR](https://github.com/LeoLakshman/SRTN_-_RR):** A web application that simulates and visualizes the **Shortest Remaining Time Next (SRTN)** and **Round Robin** CPU scheduling algorithms, combining algorithmic reasoning with interactive user experience.
* **[TTU-PhD-Around-the-Global-byLeo](https://github.com/LeoLakshman/TTU-PhD-Around-the-Global-byLeo):** A 3D globe visualization showing TTU CS PhD applicants by geography, highlighting how large-scale datasets can be translated into intuitive visual stories.
* **[TTU-Around-the-Global-byLeo-](https://github.com/LeoLakshman/TTU-Around-the-Global-byLeo-):** A geographic dashboard with interactive city selection and deeper student detail pages, demonstrating data-rich web experiences and user-centered design.
* **[GlobeTTU](https://github.com/LeoLakshman/GlobeTTU):** A globe-based visualization app focused on presenting spatial relationships and data patterns in an engaging, interactive format.
* **[ai_human_detection_project](https://github.com/LeoLakshman/ai_human_detection_project):** A machine learning project focused on building classifiers to distinguish AI-generated text from human-written content, reflecting my interest in applied AI and model evaluation.
