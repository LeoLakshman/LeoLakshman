## 🌟 Featured Projects

Here are some of my most notable projects:

* **[TTU-PhD-Around-the-Global-byLeo](https://github.com/LeoLakshman/TTU-PhD-Around-the-Global-byLeo):** An interactive **3D globe visualization** showing TTU CS PhD applicants by country and location.
* **[TTU-Around-the-Global-byLeo-](https://github.com/LeoLakshman/TTU-Around-the-Global-byLeo-):** A globe-based project with clickable city buttons linking to student detail pages.
